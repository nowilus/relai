# Fonty strony — pochodzenie i licencje

Kopie plików z `docs/zasoby/fonts/` (pochodzenie każdego kroju opisuje
[docs/zasoby/fonts/LICENCJE.md](../../docs/zasoby/fonts/LICENCJE.md)). Strona ładuje je
z własnego adresu, bez CDN. Podzbiory `latin` i `latin-ext` są potrzebne oba: `latin-ext`
niesie „ą ć ę ł ń ś ź ż”.

| Hanken Grotesk Variable | `hanken-grotesk-latin.woff2`, `hanken-grotesk-latin-ext.woff2` | treść i przyciski | SIL Open Font License 1.1 |
| Kalam 400 i 700 | `kalam-400-*.woff2`, `kalam-700-*.woff2` | notatki na karteczkach | SIL Open Font License 1.1 |
| JetBrains Mono 400 | `jetbrains-mono-latin.woff2`, `jetbrains-mono-latin-ext.woff2` | komendy do skopiowania | Apache License 2.0 |
